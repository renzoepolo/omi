# Instrucciones para agentes

Este repositorio mantiene sus instrucciones para agentes en un solo lugar para
que no se desincronicen entre herramientas.

👉 **Leé [`CLAUDE.md`](CLAUDE.md)** — resume el proyecto, los comandos, las
reglas que no se pueden romper y los comportamientos que sorprenden.

Desde ahí se entra a la documentación de arquitectura en
[`docs/architecture/`](docs/architecture/README.md), que describe el
repositorio como un grafo navegable (mapa de servicios, flujos de request,
invariantes del dominio, playbooks y un `repo-graph.json` consultable).
